# Trace 文件来源

HiTrace 二进制采集及应用自采集仅对实际生成在 `/data/log/hitrace/` 下的文件处理
`user.trace_source` 扩展属性，取值为 `system` 或 `user`。目录外文件由用户管理，
跳过标签读取、设置与清理，已有标签也不改写。判断使用规范化后的实际输出路径，
`/data/log/hitrace-other/` 等相似前缀不属于管控目录，指向目录外文件的符号链接也不属于。

进入管控范围后，来源由生成模式和请求参数决定，不依据调用进程身份判断。
标签不表示采集成功或内容完整；创建文件后、写入内容前建立来源，
初始化失败、部分写入失败或进程退出后留存的文件保留已经建立的来源。
命令行文本、压缩和重定向输出沿用原有行为，不增加来源处理。

## 场景与标签

| 场景 | 实际落盘在管控目录内 | 实际落盘在管控目录外 |
|---|---|---|
| 同步 `DumpTrace()` 不带输出路径，创建新快照 | `system` | 接口默认在管控目录内输出 |
| 同步请求指定文件或目录，创建新快照 | `user`，包括显式指定默认目录 | 不处理标签 |
| 异步 `DumpTraceAsync()` 实际落盘 | `system`；接口没有输出路径参数 | 无此输出路径参数 |
| `CacheTraceOn()` 生成缓存切片 | `system` | 缓存仍在默认目录生成 |
| 缓存经不带输出路径的同步请求转换 | `system` | 不增加移动到目录外的行为 |
| 缓存经显式指定输出路径的同步请求转换 | `user`，包括请求路径在目录外的情况 | 转换仍在原目录重命名 |
| 缓存经异步请求转换 | `system` | 不增加移动到目录外的行为 |
| `RecordTraceOn()` 默认路径或显式路径 | `user` | 不处理标签 |
| 录制按大小分片、输出文件移除后重建 | 每次创建时设置 `user` | 每次创建时跳过标签处理 |
| 命令行 raw / `--record` | 沿用录制接口，为 `user` | 不处理标签 |
| 命令行后台快照 `--dump_bgsrv` | 沿用同步快照来源规则 | 不处理标签 |
| boot trace，包括递增文件 | 明确传入输出路径，为 `user` | 默认 `/data/local/tmp` 及目录外自定义路径不处理标签 |
| 应用自采集 `StartCaptureAppTrace()` | 接口允许且能成功打开的指定路径为 `user` | 默认应用沙箱和目录外指定路径不处理标签 |
| 仅复用已存在的快照 | 保留既有来源，不重新分类 | 不处理标签 |
| 命令行文本、压缩及重定向输出 | 沿用原有行为，不新增标签处理 | 不处理标签 |
| 异步读取阶段、trace marker、仅停止且不输出 | 不创建 trace 文件 | 不创建 trace 文件 |

输出路径仍接受各接口原有校验，本次不扩展接口允许的目录或调用权限。
新建输出与替换输出 fd 都根据本次实际路径判断是否进入来源处理。
缓存转换仍在原目录重命名，不复制到请求路径：因此请求路径在目录外，
不等于转换文件实际位于目录外。缓存转换使用请求来源，后续复用快照不改回来源。
历史快照即使使用 `cache_` 开头的自定义文件名，也不会被当作缓存转换；归类依据实际所属列表。

## 写入和转换

二进制输出工厂在创建或替换输出 fd 时建立管控目录内文件的来源，不新增写入文件锁。
管控目录内标签建立失败时终止写入并尝试清理，不把未建立来源的新文件当作成功输出。
目录外直接跳过标签操作，不因来源属性写入权限不足而中断原有采集。
文件创建、xattr 和清理不是文件系统原子事务；文件系统异常时清理也可能失败。

缓存转换按转换请求设置来源，然后重命名，不新增转换文件锁。失败的转换不加入结果列表，
也不计入该次结果的文件大小和覆盖时长；重命名失败时尝试恢复缓存的 `system` 来源。
如果仍有其它有效文件，沿用部分结果成功规则；无可返回文件且转换失败时返回写入错误。
转换不刷新 `mtime`。原缓存路径在下一轮容量核对时退出缓存预算。
异步延迟完成回调、快照复用索引和任务内存回收沿用原逻辑，来源处理不调整这些业务流程。

## 老化边界

`AgeTraceFile()` 仍仅扫描默认目录，按 `system` 标签、`mtime`、保留时间及文件锁判断，
不新增递归扫描。转换成 `user` 的快照不再属于该接口的系统时间老化对象。
录制数量/容量清理和缓存容量清理仍按各自策略执行，`user` 不代表文件永不删除。
本规格不批量迁移历史文件，也不处理设备外转换工具创建的派生文件。
